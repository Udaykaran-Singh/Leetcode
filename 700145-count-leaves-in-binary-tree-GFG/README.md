# [Count Leaves in Binary Tree](https://www.geeksforgeeks.org/problems/count-leaves-in-binary-tree/1)
## Easy
Given a Binary Tree, you need to count leaves in it.&nbsp;Examples:Input: root[] = [4, 8, 10, 7, 5, 1, 3]
Output: 3
Explanation: Three leaves are 3, 5 and 1.Input: root[] = [50, 30, 70, 20, 40, 60, 80, 65]Output: 4
Explanation: Four leaves are 20, 40, 65 and 80.Input: root[] = [30, 25, 35, 20, 28, 40, 27] Output: 3
Explanation: Three leaves are 20, 27 and 40.
